# Fotos de las paradas científicas ("lo que verás al llegar")

Una imagen por punto de `ui/data/poi.js`, con el nombre `<id>.jpg` (p. ej. `murray-buttes.jpg`).
Para activarla, pon `foto: 'poi/<id>.jpg'` y `fotoCredito` en el punto correspondiente.

Pendiente: la sesión que creó esto no tenía red hacia mars.nasa.gov (proxy 403), así que no hay fotos todavía.
Cada punto trae `fotoSugerida` (cámara y sol) para buscarla en https://mars.nasa.gov/msl/multimedia/raw-images/
Crédito de las imágenes crudas de MSL: NASA/JPL-Caltech (Navcam) · NASA/JPL-Caltech/MSSS (Mastcam).
